📁 Структура папок
Для коректної роботи гри всі ресурси мають знаходитися у папці img/ поруч із головним файлом гри (index.html):

img/PLAYER_TANK.svg — танк гравця

img/ENEMY_TANK.svg — танк ворога

img/grass_1.svg — перший варіант трави / кущика

img/grass_2.svg — другий варіант трави / кущика

⚙️ Налаштування пікселізації та ефектів (PIXEL_CONFIG)
На початку скрипту гри ви можете налаштовувати параметри у блоці PIXEL_CONFIG для досягнення ідеального візуального стилю:

JavaScript
const PIXEL_CONFIG = {
    scale: 2,          // Множник пікселізації (1 = оригінал 1280x720, 2 = роздільна здатність у 2 рази менша, крупніші пікселі)
    pixelated: true,   // true - вмикає чіткий pixel-art стиль без розмиття (image-rendering: pixelated)
    crtLines: true     // true - залишає ефект класичних смужок CRT-монітора поверх екрана
};
🎮 Керування у грі
[A] / [D] або [Стрілка Вліво] / [Стрілка Вправо] — керування двигуном та пересування танка вздовж рельєфу.

[Миша] (Наведення) — обертання гармати танка за курсором.

[Клік лівою кнопкою миші] — вогонь / постріл снарядом.

Клік після Game Over — перезапуск місії.

🛠 Технічні особливості реалізації
Динамічний піксельний рендеринг: Роздільна здатність Canvas розраховується автоматично на основі коефіцієнта scale, а властивість imageSmoothingEnabled = false разом із CSS-стилями запобігає будь-якому розмиттю.

Рандомна трава: Під час генерації ландшафту декорації автоматично рандомно підтягують файли grass_1.svg або grass_2.svg.

Глибина шарів (Z-index): Гармати (дула) танків завжди рендеряться за корпусом, створюючи правильну перспективу та глибину.
